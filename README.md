Python repository which parses CS2 demo files and extracts data for a postgres DB

Parser: https://github.com/LaihoE/demoparser

Relevant files:
- main.py: entry point

- parse.py: actually parse the demos

- data.py: classes for all database tables, methods for everything database related

- /demos/: sctips for parsing individual items

- /query-to-sheets/: sql files for different stats
